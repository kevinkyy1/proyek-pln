PANDUAN MENJALANKAN APLIKASI DI WINDOWS
Aplikasi Data Table Pemakaian Pelanggan (import Excel TO LPB)
=========================================================================

Isi berkas ini
  1. Tentang aplikasi
  2. Yang harus dipasang (sekali saja)
  3. Menyiapkan project
  4. Menjalankan aplikasi (3 jendela)
  5. Cara pakai di browser
  6. Format file Excel yang bisa diimpor
  7. Konfigurasi penting
  8. Kalau ada masalah
  9. Perintah yang sering dipakai
 10. Ringkasan cepat (tiap kali mau bekerja)


-------------------------------------------------------------------------
1. TENTANG APLIKASI
-------------------------------------------------------------------------
- Kerangka    : Laravel 12 (butuh PHP 8.2 atau lebih baru), basis data MySQL
- Fungsi      : menampilkan data pemakaian listrik per pelanggan (IDPEL)
                seperti sheet MASTER pada file Excel TO LPB, lengkap dengan
                grafik tren pemakaian.
- Data disimpan di dua tabel:
      pelanggan          (idpel, nama, tarif, daya)
      pemakaian_bulanan  (idpel, periode, kwh)   -> satu baris per bulan
- File Excel yang besar (45-55 MB, sekitar 160 ribu baris) dibaca bertahap
  lewat antrean (queue): dipotong 20.000 baris per job.
  Sebab itu WAJIB ada queue worker yang berjalan saat mengimpor.


-------------------------------------------------------------------------
2. YANG HARUS DIPASANG (SEKALI SAJA)
-------------------------------------------------------------------------
a) XAMPP versi PHP 8.2 atau lebih baru
   - Unduh di https://www.apachefriends.org (pilih versi 8.2.x / 8.3.x / 8.4.x)
   - Pasang misalnya di C:\xampp
   - Apache TIDAK wajib dijalankan; yang wajib hanya MySQL
   (Alternatif: Laragon, isinya sama: PHP + MySQL + composer)

b) Composer (pengelola paket PHP)
   - Unduh Composer-Setup.exe di https://getcomposer.org/download
   - Saat pemasangan, arahkan ke php.exe milik XAMPP, contoh:
     C:\xampp\php\php.exe
   - Periksa di PowerShell:  composer -V
   - Kalau Anda memakai composer.phar, gantinya: php composer.phar install

c) Node.js LTS (untuk membangun tampilan dan grafik)
   - Unduh di https://nodejs.org (pilih versi LTS, 20 atau lebih baru)
   - Periksa:  node -v   dan   npm -v

d) (Opsional) Git for Windows, kalau ingin memakai riwayat versi.

e) Pastikan ekstensi PHP berikut aktif:
       pdo_mysql, dom, xml, xmlreader, xmlwriter, zip, fileinfo, openssl,
       mbstring, curl
   Di XAMPP ekstensi tersebut sudah aktif sejak pemasangan. Cara memeriksa:
       php -m
   Kalau ada yang belum aktif, buka C:\xampp\php\php.ini, hilangkan tanda
   ";" di awal barisnya, simpan, lalu tutup semua terminal lama dan buka lagi.


-------------------------------------------------------------------------
3. MENYIAPKAN PROJECT
-------------------------------------------------------------------------
  1) Ekstrak salinan project ini ke folder kerja, misalnya
       C:\xampp\htdocs\pln
     (boleh juga C:\proyek\pln, lokasinya bebas)

  2) Buka PowerShell di folder tersebut:
       buka foldernya di File Explorer, klik kanan sambil menekan Shift,
       pilih "Open PowerShell window here"

  3) Pasang dependensi PHP
       composer install

  4) Siapkan berkas pengaturan lingkungan
       copy .env.example .env
       php artisan key:generate

  5) Sunting berkas .env pakai Notepad, isi seperti ini:
       APP_ENV=local
       APP_DEBUG=true
       APP_URL=http://localhost:8000
       DB_CONNECTION=mysql
       DB_HOST=127.0.0.1
       DB_PORT=3306
       DB_DATABASE=pln
       DB_USERNAME=root
       DB_PASSWORD=
       QUEUE_CONNECTION=database
     (DB_PASSWORD dibiarkan kosong kalau MySQL XAMPP belum diberi sandi)

  6) Buat basis datanya, salah satu cara:
     - lewat phpMyAdmin: buka http://localhost/phpmyadmin, klik New,
       nama database: pln, collation: utf8mb4_unicode_ci, klik Create
     - atau lewat perintah:
       C:\xampp\mysql\bin\mysql.exe -u root -e "CREATE DATABASE pln CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

  7) Buat tabel-tabelnya
       php artisan migrate --force

  8) Pasang dependensi tampilan
       npm install

  9) php.ini TIDAK perlu disunting.
     Aplikasi sudah disetel agar jalan dengan nilai bawaan PHP, karena berkas
     Excel diunggah bertahap 1 MB per permintaan (lihat bagian 7). Kalau di
     komputer Anda batasnya justru dinaikkan, aplikasi tetap jalan normal.

  Catatan: berkas .env, folder vendor, dan folder node_modules tidak ikut
  di dalam arsip ZIP, jadi langkah 3, 4, dan 8 harus dijalankan setelah
  mengekstrak.


-------------------------------------------------------------------------
4. MENJALANKAN APLIKASI (3 JENDELA POWERSHELL)
-------------------------------------------------------------------------
Buka 3 jendela PowerShell, semuanya di folder project (C:\xampp\htdocs\pln).
Pastikan MySQL sudah jalan dari XAMPP Control Panel.

  Jendela 1 - server aplikasi
      php artisan serve --host=127.0.0.1 --port=8000

  Jendela 2 - pembangun tampilan (mode pengembangan)
      npm run dev

  Jendela 3 - worker antrean (wajib saat mengimpor data)
      php artisan queue:work --tries=3 --sleep=1 --memory=128 --timeout=3600
      (--memory=128 sama dengan nilai bawaan Laravel. Saat diuji dengan file
       45 MB, pemakaian memori worker hanya sekitar 50 MB, jadi 128 MB aman
       dan tidak melampaui memory_limit bawaan PHP)

Lalu buka peramban:  http://localhost:8000

Keterangan tambahan
- Kalau malas menjalankan "npm run dev" terus-menerus, jalankan sekali
  "npm run build", setelah itu cukup 2 jendela: server + worker.
- Port 8000 sedang dipakai program lain? Pakai --port=8001, dan ubah
  APP_URL di .env menjadi http://localhost:8001.
- Ingin worker tetap jalan sambil jendela ditutup? Jalankan:
  start /B php artisan queue:work --tries=3 --sleep=1 --memory=128 --timeout=3600
  Tetapi menjalankannya di jendela tersendiri lebih enak, karena progres
  job bisa dilihat langsung.
- Komputer ini mati/restart, ulangi lagi bagian 4 (lihat juga bagian 10).


-------------------------------------------------------------------------
5. CARA PAKAI DI BROWSER
-------------------------------------------------------------------------
a) Mengimpor data
   1. Klik tombol "Import Excel" di kanan atas.
   2. Pilih berkas .xlsx (isinya sheet MASTER), lalu klik Upload.
   3. Berkas dikirim ke server bertahap 1 MB per bagian, jadi file besar
      tidak mentok di batas unggah bawaan PHP.
   4. PENTING: impor bersifat ganti-total. Tabel pelanggan dan
      pemakaian_bulanan dikosongkan dulu, baru diisi data baru. Jangan
      mengimpor ketika masih ada batch yang sedang berjalan.
   5. Pantau panel "Riwayat import (5 terakhir)" yang menyegarkan sendiri
      tiap 5 detik:
      queued -> preparing (baca berkas & deteksi kolom) -> processing
      (mis. 40.000/160.564 baris) -> completed (atau failed).
   6. Import 160 ribu baris biasanya makan 10-20 menit, tergantung
      kecepatan komputer.

b) Melihat tabel
   - Kotak "Cari": mencari IDPEL, NAMA, atau TARIF. Isi kata kuncinya lalu
     tekan tombol Cari atau tombol Enter (sekadar mengetik tidak
     menjalankan pencarian).
   - Pilihan baris per halaman: 25 / 50 / 100 / 250, ada juga navigasi halaman.
   - Kolom bulan mengikuti header berkas yang terakhir diimpor. Kalau di
     Excel Anda menambah kolom 202701 lalu impor ulang, kolom itu otomatis
     muncul tanpa perlu ubah program.
   - Tiap tahun punya tiga kolom RATA2:
       PEM = rata-rata kWh dari bulan yang ada datanya
       JN  = PEM x 1000 / DAYA
       KET = rumus IF(JN<1,"TBT", IF(JN>40,"NORMAL","40JN"))
   - Angka ditampilkan bulat mengikuti format sel Excel (94,5 menjadi 95);
     nilai aslinya tetap desimal di database.
   - Kolom No, IDPEL, dan NAMA tetap menempel di kiri saat tabel digeser
     ke samping.

c) Grafik tren pemakaian
   - Klik salah satu nilai IDPEL pada tabel.
   - Muncul jendela "Tren Pemakaian" berisi:
       - tabel nilai per bulan: baris PEM dan JAM NYALA (angka bulat),
       - grafik garis dua deret: PEM (sumbu kiri, kWh) dan JAM NYALA
         (sumbu kanan) = PEM x 1000 / DAYA.
   - Di bawah sumbu X tertera bulan, nilai PEM, dan nilai JN. Pada layar
     sempit label dijarangkan dan grafik bisa digeser ke samping.
   - Bulan yang belum ada nilainya digambar 0, mengikuti rumus sheet
     GRAFIK di Excel yang memakai default "0".
   - Tutup jendela dengan tombol x, klik di luar kotak, atau tombol Esc.


-------------------------------------------------------------------------
6. FORMAT FILE EXCEL YANG BISA DIIMPOR
-------------------------------------------------------------------------
- Sheet sumber: MASTER (bisa diubah di config/import.php, kunci "sheet").
- Baris 1: header.
      Kolom A = IDPEL, B = NAMA, C = TARIF, D = DAYA
      Kolom berikutnya berisi bulan dengan format YYYYMM
      (202401, 202402, ... 202612, 202701, dan seterusnya).
      Kolom bulan dikenali otomatis dari header, jumlahnya bebas.
- Baris 2: sub-header (PEM/JN/KET) - diabaikan aplikasi.
- Baris 3 dan seterusnya: data pelanggan.
- Kolom RATA2 di berkas tidak dibaca; aplikasi menghitungnya sendiri.
- Baris yang sedang disembunyikan filter Excel tetap ikut diimpor, karena
  semua baris dibaca apa adanya.
- Kolom DAYA dipakai untuk menghitung Jam Nyala, jadi sebaiknya terisi.


-------------------------------------------------------------------------
7. KONFIGURASI PENTING
-------------------------------------------------------------------------
config/import.php
    sheet              nama sheet sumber (default MASTER)
    chunk_size         jumlah baris per job (default 20000)
    upload_chunk_size  ukuran potongan unggah dari browser (default 1 MB)
    data_start_row     baris awal data (default 3)
    periode_start/count  hanya cadangan tampilan kalau belum ada import;
                       kolom bulan normalnya dibaca dari header berkas

config/queue.php
    retry_after = 3600  job chunk butuh waktu lama. Kalau nilainya kecil,
                        job dianggap gagal dan diulang padahal masih jalan.

.env
    QUEUE_CONNECTION=database   antrean disimpan di tabel jobs
    APP_URL                     harus sama dengan alamat yang dibuka di browser

php.ini (C:\xampp\php\php.ini) - TIDAK perlu diubah
    Nilai bawaan PHP sudah cukup untuk aplikasi ini:
        upload_max_filesize = 2M     cukup, karena tiap permintaan unggah ~1 MB
        post_max_size       = 8M     cukup, karena tiap permintaan unggah ~1 MB
        memory_limit        = 128M   cukup; worker dijalankan dengan --memory=128
                                     (uji nyata file 45 MB: puncak ~50 MB)
        max_execution_time  = 30     tidak berpengaruh pada worker (di mode
                                     terminal/CLI PHP memaksa nilai ini 0)
    Cara memeriksa nilai yang sedang dipakai:
        php -r "foreach(['upload_max_filesize','post_max_size','memory_limit'] as $k) echo $k, ' = ', ini_get($k), PHP_EOL;"
    Kalau komputer Anda sudah memakai nilai lebih besar, tidak masalah —
    aplikasi tetap jalan.

8. KALAU ADA MASALAH
-------------------------------------------------------------------------
- Muncul "'php' is not recognized as an internal or external command"
  PHP belum masuk PATH. Pakai path lengkap, contoh:
      C:\xampp\php\php.exe artisan serve
  atau tambahkan C:\xampp\php (dan C:\Program Files\nodejs) ke PATH Windows.

- Composer menolak karena versi PHP kurang
  Laravel 12 butuh PHP 8.2+. Cek dengan "php -v". Kalau XAMPP Anda masih
  PHP 8.0 atau 8.1, pasang XAMPP versi 8.2 ke atas.

- Import diam di "0 / N baris" atau status queued terus
  Penyebab tersering: worker antrean tidak jalan. Pastikan Jendela 3
  (queue:work) benar-benar berjalan.

- Muncul "The POST data is too large"
  Ukuran potongan unggah melebihi post_max_size. Aplikasi memakai 1 MB per
  potongan, jadi dengan nilai bawaan PHP (8M) ini tidak terjadi. Kalau Anda
  pernah menaikkan konfigurasi dan lalu mengembalikannya, tutup semua proses
  PHP lama (Task Manager) lalu jalankan lagi "php artisan serve".

- Job gagal berulang
      php artisan queue:failed          (lihat daftar job gagal)
      php artisan queue:retry all       (coba jalankan lagi)
      notepad storage\logs\laravel.log  (lihat keterangan kesalahan)

- Worker berhenti sendiri di tengah import
  Pemakaian memori job melewati batas --memory. Pakai --memory=128 dan
  --timeout=3600. Untuk file Excel yang jauh lebih besar (mis. di atas
  100 MB), naikkan memory_limit di php.ini lebih dulu (mis. 512M atau -1),
  baru naikkan --memory.

- Sudah mengubah program di app\Jobs tetapi perilakunya tidak berubah
  Worker masih memuat kode lama. Jalankan:
      php artisan queue:restart

- Port 8000 atau 5173 sudah dipakai
  Ganti port: php artisan serve --port=8001 (sesuaikan APP_URL), atau
  hentikan program lain yang memakai port tersebut.

- Import terasa sangat lambat
  Pastikan MySQL berjalan normal dan jangan menjalankan banyak worker
  sekaligus (1 worker sudah cukup). Bisa juga menaikkan innodb_buffer_pool_size
  di C:\xampp\mysql\bin\my.ini (mis. 512M) lalu restart MySQL.

- Ingin unggahan lebih cepat
  Naikkan upload_chunk_size di config/import.php (atau tulis
  IMPORT_UPLOAD_CHUNK_SIZE di .env) menjadi mis. 8 MB, TAPI nilai
  post_max_size dan upload_max_filesize di php.ini harus lebih besar dari itu.

- Tabel kosong setelah import selesai
  Periksa jumlah barisnya lewat phpMyAdmin, atau:
      C:\xampp\mysql\bin\mysql.exe -u root -D pln -e "select count(*) from pelanggan; select count(*) from pemakaian_bulanan;"

9. PERINTAH YANG SERING DIPAKAI
-------------------------------------------------------------------------
    # jumlah data
    C:\xampp\mysql\bin\mysql.exe -u root -D pln -e "select count(*) from pelanggan; select count(*) from pemakaian_bulanan;"

    # riwayat import
    C:\xampp\mysql\bin\mysql.exe -u root -D pln -e "select id, file_name, status, total_rows, processed_rows from import_batches order by id desc limit 5"

    # daftar bulan yang sudah ada datanya
    C:\xampp\mysql\bin\mysql.exe -u root -D pln -e "select periode, count(*) from pemakaian_bulanan group by periode order by periode"

    # hapus semua data dan bangun ulang tabel
    php artisan migrate:fresh --force

    # muat ulang kode job di worker
    php artisan queue:restart

    # bangun tampilan sekali saja (tanpa npm run dev)
    npm run build

10. RINGKASAN CEPAT (TIAP KALI MAU BEKERJA)
-------------------------------------------------------------------------
    1. XAMPP Control Panel -> Start MySQL
    2. Jendela 1: php artisan serve --host=127.0.0.1 --port=8000
    3. Jendela 2: npm run dev
    4. Jendela 3: php artisan queue:work --tries=3 --sleep=1 --memory=128 --timeout=3600
    5. Buka browser: http://localhost:8000
    6. Import data, lihat tabel, klik IDPEL untuk melihat grafik tren
